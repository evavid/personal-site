This is a starter post. Replace it with your own, or delete this file. Every Markdown file in `src/content/posts/` becomes a page under `/writing/`.

## How a post works

The block at the top of the file (the *frontmatter*) sets the title, date and category. The category has to be `ai`, `life` or `technology`. Reading time is worked out from the word count.

```yaml
title: "My post title"
date: 2026-10-02
category: ai
excerpt: "One sentence that shows up in lists and in the RSS feed."
project: alpine-weather-bot   # optional
draft: true                   # optional: hidden from the live site
```

## Linking a project

Add `project:` with the name of one of your GitHub repositories. The post then ends with a "Code for this post" link to the repo, and the project's page lists the post under "Written about it".
